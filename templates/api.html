Developer API

Publish with the API

Use one HTTP endpoint to publish PDF, HTML, Markdown, plain text and images. Write requests need the admin key; reading endpoints are public.

In the examples, BASE_URL is the public origin of this installation, and API_KEY is the admin key configured on the server.

Upload

POST /api/upload

curl --fail-with-body -sS \
  -X POST $BASE_URL/api/upload \
  -H "X-API-Key: $API_KEY" \
  -F "file=@report.pdf" \
  -F "title=Quarterly report" \
  -F "tags=report,public"

Optional fields: title, description, tags (comma separated, up to five).

Authentication

Send the key in either header:

X-API-Key: $API_KEY
Authorization: Bearer $API_KEY

The key is the API_KEY value in the server .env. It also unlocks the private studio.

Raw binary

Send file bytes directly and pass the filename in the query string.

curl --fail-with-body -sS \
  -X POST "$BASE_URL/api/upload?filename=report.pdf" \
  -H "X-API-Key: $API_KEY" \
  --data-binary @report.pdf

Manage documents

  • GET /api/documents — list, filter and paginate
  • GET /api/documents/{id} — metadata
  • PUT /api/documents/{id} — replace and archive a version
  • DELETE /api/documents/{id} — delete
  • GET /api/documents/{id}/versions — version history

Markdown images

External images and inline base64 images are downloaded and rewritten to local /media/... links at upload time.

  • Public HTTP(S) only; private, loopback and SVG sources are skipped.
  • 8 MB per image, 32 images and 32 MB per document.
  • Failed downloads keep the original URL and are logged.

Errors

  • 401 — missing or incorrect API key
  • 400 — no file, empty file or missing filename
  • 413 — file exceeds the per-file limit
  • 415 — unsupported extension
  • 507 — total storage quota exceeded
